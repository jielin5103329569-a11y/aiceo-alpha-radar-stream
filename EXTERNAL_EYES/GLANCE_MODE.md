# 外部雷达一览模式
锁定: 2026-09-24 16:13 PT
Owner: 以后都用这个模式
不买。不接实盘。不改旧扫描包。

## 输出
1. 顶行提醒=本小时进入/停在阶段2或阶段3的票；否则无
2. 简体一览表，栏顺序固定：
   票 | 阶段(1-4) | 风险(1-10) | 成功率 | 催化力度(1-10) | 偏好 | 方向 | 状态一句
3. 方向=利多 / 利空 / 中性（只看发行人原件对预期差的方向）
4. 偏好=主盯 / 次盯 / 池内 / 观察 / 低
5. 新当期报告确认或推阶段，才在该行下写发K简介（最多两句+链接+申报时间）。无推进原件不造。
6. 同时更新整池图 / 总览页，便一键看全表
7. 文字用简体；只保留票代码与当期报告表名
8. 票池不丢，直到燃尽三门
