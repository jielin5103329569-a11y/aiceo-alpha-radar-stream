A｜REALITY BOTTLENECKS

A1｜Advanced Packaging / Heterogeneous Integration

Reality change：YES

Amkor 9/8 官方宣布 Arizona Advanced Packaging and Test Campus Phase 2：原 Phase 1 规划 33,000 平方米洁净室，但公司称客户 commitments 已超过 Phase 1 容量，因此新增约 60,000 平方米，总洁净室约 93,000 平方米，项目计划投资提高至约 $12B。这是客户承诺推动实体产能扩张的现实证据，而不只是行业预测。

与此同时，TrendForce 9/18 指出 AI GPU 与 hyperscale CSP 正继续推动更大封装尺寸，CoWoS-L 预计仍将是未来数年重要 2.5D AI 封装路线。该证据支持“先进封装复杂度/有效产能仍是 AI compute scaling 的现实约束”，但行业预测本身不等于单一公司的订单确认。

Hidden X：
先进封装的约束正在从单纯“有没有 CoWoS”向 large-body heterogeneous integration → thermal / warpage / power delivery / yield → 可规模制造迁移。

Unknown：
Phase 2 客户 commitments 的具体客户、产品、wafer/package 数量与年度收入贡献尚未全部公开。

Next milestone：
客户/产品级 capacity allocation、量产时间、HDFO/2.5D/CPO 实际 volume ramp。

A2｜Power Path Compression / 800V DC

Reality change：YES — stronger

Google、Microsoft、NVIDIA 已通过 OCP 共同推动 800 VDC 成为下一代 AI 数据中心开放标准；NVIDIA 8/11 明确称已有 80+ equipment manufacturers / infrastructure companies 围绕该规范开发产品。NVIDIA 同时给出从现有 AC 设施的 hybrid 800V power rack 到未来 facility-scale DC power block 的迁移路径。

Bloom Energy 9/16 又给出新的具体产业表达：其 fuel-cell 架构可直接输出 800V DC，并声称能够移除部分传统 AC conversion / transformer 环节。这里的成本数字属于公司自己的工程经济测算，不能当作行业已经实现的成本事实；但它是“哪些 BOM 节点可能被压缩/移除”开始具体化的证据。

此外，ABB 相关 800V DC source-to-rack 产品架构已开始覆盖 solid-state conversion、distribution、protection 等组件，显示供应链正在从标准讨论向具体产品层移动。

Hidden X：
下一瓶颈不再只是“800V 是否成立”，而是：
谁成为不可绕过的 conversion / protection / DC-DC / SST / busway / rack-power 节点，以及哪些旧 AC BOM 被永久压缩。

Unknown：
尚未看到足够公开的 hyperscaler 大规模采购 BOM，证明最终 economic rent 稳定落在哪一个不可绕过节点。

Next milestone：
真实 hyperscaler deployment / procurement + MW/GW + vendor BOM + 被删除设备清单。

A3｜Grid / Interconnection / Power-Cost Endogenization

Reality change：YES

California ISO 的 Large Loads Initiative 已推进至 Draft Final Proposal + draft tariff language；9/24 已进入正式文本阶段，10/1 安排 stakeholder meeting，后续还有 tariff-language meeting 与 Board 时间表。议题包括提高大型负荷信息可见度以及新的可靠性技术标准。

MISO 也继续推进 Large Load Interconnection Reliability Requirements，9/23 已出现新的工作组材料。

这进一步支持此前 External Eyes 的核心现实判断：

AI 数据中心的“电力成本”正在从外部条件逐步内生化为项目选址、并网、资本需求和运行约束。

Hidden X：
真正稀缺的可能不是 nominal generation MW，而是：
可及时交付 + 可并网 + 满足 reliability requirement + 成本分配可接受的 MW。

Unknown：
各 ISO / state 最终 tariff 如何改变单个 hyperscaler 项目 economics，仍需等待正式实施与真实项目反应。

Next milestone：
项目因 interconnection/tariff 成本改变地点、架构或 behind-the-meter 方案的可验证案例。

A4｜Optical / CPO / NPO / InP

Reality change：YES

Coherent 9/21 正式发布 PhotonLink integrated optics platform，直接面向下一代 AI datacenter，覆盖 CPO、NPO 和 chip-to-chip connectivity，把 laser、silicon photonics、precision optics、fiber、detector、assembly/test 组合成完整平台。

ECOC 2026 又展示了包括 448 Gb/s per lane InP MZM-SOA array PIC、CPO/NPO、next-generation pluggables、specialty fiber 与 thermal-management 等实际技术路径。

这不是“CPO 已全面替代 pluggable”的证据，而是 optical I/O 正继续向 compute/switch silicon 靠近，且 InP / laser / integration / packaging / thermal 的联合约束正在变得更具体。

Hidden X：
光学瓶颈可能由单器件性能迁移为：
laser + PIC + package + fiber attach + thermal + test/yield 的系统级制造约束。

Unknown：
CPO/NPO 与 1.6T/3.2T pluggable 的实际 volume crossover 时间仍未确认。

Next milestone：
hyperscaler production deployment、volume order、yield/capacity 或明确 BOM。
