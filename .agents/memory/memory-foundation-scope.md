---
name: Memory foundation scope
description: Durable authority and scope boundary for the first AICEO memory foundation.
---

G1-001 is a candidate-only memory foundation. Ordinary agents and external sources may persist only immutable, project-isolated, unverified observation, interpretation, or hypothesis candidates with explicit provenance and temporal validity. Candidate creation emits a database-owned, monotonic, append-only lifecycle event.

Thought Continuity Graph is part of the G1-001 core contract, not a later retrieval feature. It preserves an immutable causal path from motivation and context through observation, interpretation, belief/hypothesis, principle, decision, action, outcome, reflection, updated belief, and next decision. Counterfactual and outcome evidence is content/provenance-bound, outcomes must point to a causal action ancestor, and updated beliefs supersede rather than rewrite prior thought.

Repeated citation never upgrades a thought to fact or rule. Independent evidence, explicit epistemic state, observed outcomes, counterfactuals, and supersession preserve continuity while allowing reality to contradict earlier judgment.

Learning Promotion, Retrieval Router, Context Compiler, Agent Memory Distribution, and Temporal Replay remain explicitly deferred and non-executable. Persistent State remains the engineering truth; memory candidates are context and cannot change governance or authority.

**Why:** Attempting to include promotion in the minimum foundation repeatedly created avoidable authority-forgery and evidence-laundering surfaces and violated the stated deferral of Learning Promotion. Thought continuity is safe only when causal history cannot self-certify truth.

**How to apply:** Do not add a promotion route, callable promotion function, trusted-memory write, or general retrieval behavior while operating under G1-001. Narrow causal backtrace may read one graph path but cannot rank, promote, compile, or distribute memory. Later modules must begin from their own blocked Resume Node and pass independent governance and closure review.
