---
name: Three-stage core learning policy
description: The permanent priority framework for Alpha Radar's background learning and data-value evaluation.
---

All background learning quality must serve one—and only one—of three independent core directions:

1. **Pre-breakout / latent** — identify internal strength changes and favourable risk/reward setups earlier and more accurately.
2. **True breakout** — distinguish valid structural breaks from false breaks, including breakout reality and persistence.
3. **Post-breakout trend / profit-taking** — assess trend life, continuation, exhaustion, scale-down, and profit-taking timing.

Each stage retains separate models, feature weights, outcome statistics, matched baselines, and independent holdouts. All stages use the same data-value criteria: predictive power, earliness, risk/reward improvement, incremental information value, stability, and noise/false-signal rate.

**Why:** The user confirmed these are the highest-priority directions for all future learning. Data, metrics, features, and learning results that cannot explicitly improve at least one direction must not enter the core learning system.

**How to apply:** Keep experiments in the Shadow Learning sidecar. An item becomes a core-learning candidate only after stage mapping, complete immutable future-outcome evidence, and a successful shared-value assessment. A stage's calibration must use only its own matched baseline and holdout; evidence from another stage is never transferable. It must never directly alter live Alpha Radar scoring or alert gates without the separate approved promotion process.
