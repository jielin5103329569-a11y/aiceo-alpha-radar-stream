---
name: Sector-first priority
description: Rules for using sector context in Alpha Radar candidate ordering without inferring unavailable evidence.
---

Sector strength is a material multiplier on the individual Alpha Ranking, not an additive display score. It can only be formed from multiple independently fresh, verified protected live windows with a trusted fresh reference classification.

Final-candidate promotion requires all independent confirmation inputs: current market evidence, ranked sector strength, catalyst, money flow, options activity, fundamentals, valuation/expectation, and risk/reward. A pre-breakout designation also needs unfinished expansion. Any unavailable input leaves the symbol unranked in an explicit withheld state.

**Why:** The product's promise is evidence integrity. Reference data describes classifications and lifecycle only; it cannot substitute for live market coverage or external confirmation. A partial setup must never look like an approved candidate.

**How to apply:** Keep sector rankings scoped to actually covered fresh symbols. When adding live universes or data providers, label their provenance and availability independently; do not promote candidates or relax existing AlertMonitor gates solely because sector context exists.
